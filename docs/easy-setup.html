Upload, then connect.

  1. Download Direct starter 1.1.0. Replace its RoboSynctUserConfig.h with the header you generated above.
  2. Open RoboSynctDirect.ino in Arduino IDE. Original ESP32 Dev Module, Espressif core 3.3.12, your actual COM port. For the confirmed 4 MB DevKit V1, choose Huge APP (3 MB No OTA). Keep Erase All Flash disabled.
  3. Upload manually. Existing board identity, phone key and history are retained. No cloud account password or service key belongs in this header.
  4. New unclaimed boards open a five-minute protected setup window after startup. Scan the private setup QR in the APK, allow Nearby devices and choose Bluetooth. If the window expired, hold BOOT for three seconds after startup.
  5. With one existing Potentiometer stream, the signed-in app maps the board to it automatically. If several streams exist, select the existing stream once. Return to the same Dashboard.
  6. Choose Online for automatic website uploads, or Offline to pause cloud traffic and keep local Bluetooth readings. When Online loses internet, readings queue and upload when it returns.

Already claimed by another phone? Physical BOOT for eight seconds resets only the board's direct claim. Do this only when intentionally replacing its phone controller. Standard Arduino Uno needs an appropriate communications module or bridge; this firmware targets the original ESP32.
