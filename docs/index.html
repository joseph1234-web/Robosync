            PHYSICAL PIN + DATA LABEL

            Stream pin setup

            A virtual pin has no physical location. Find the GPIO or A label printed on your board; V0 exists only in software. Example: wire the potentiometer to GPIO34 on ESP32 (or A0 on Uno); use V0 as its separate data label.

            This saves a wiring plan for the existing stream. It does not detect your wires or change the board firmware. Keep the same sensor pin in your compatible Arduino sketch. Uno needs its own compatible sketch/adapter; the ESP32 starter cannot run on Uno.
