On your Android phone.

Matching widget colors, sizes, icons and stream pin setup →

  1. Sign in with your existing website email/password. Your saved project opens automatically when there is one; choose if several exist.
  2. Open Devices → Connect device. Choose your existing Potentiometer stream. No device, channel or Dashboard is recreated.
  3. Prepare: if RoboSynct Direct is already uploaded, continue. Otherwise use the existing Direct 1.1 starter and private header/QR tool, then upload manually in Arduino IDE.
  4. Connect: use Bluetooth (recommended for the current ESP32) or local Wi-Fi. An enrolled board reuses its key. A new board scans its private setup QR once. Advanced settings retain manual IP, older setup code and recovery.
  5. Sync options: choose Auto-sync to queue and upload when internet returns, or Local only to keep collection/queuing while website traffic is paused. Your existing preference is retained until you choose.
  6. Verify: turn the knob. Finish is enabled after a fresh reading is mapped to the selected Dashboard stream. Website delivery is shown separately and may still be queued offline.

Back/Retry keeps the safe setup progress. No passwords are stored in wizard progress. Background sensor collection keeps the existing notification with Stop/Resume; Android force-stop, radio/range/power loss and battery policy can interrupt it.

Dashboard

One compact Board / Website strip, then your saved widgets. Use Edit / Arrange for layout controls. View and Edit use the saved card height. Both website and APK stack cards up to 720 logical pixels and use saved column widths on larger screens.

Devices

Devices linked to the saved Dashboard, readings/history, CSV and guided connection. This first release shows bound devices; it does not claim a new global device catalog.

Activity

Your existing project events and local sensor alerts. Manual, phone-local and cloud rules keep their own execution boundaries.

More

Account/project choice, Settings/themes, all streams, existing QR connection, optional camera and website tools remain reachable.

On the website.

Open your existing project → Connect device. The five-step guide reuses its saved device and streams, links to the matching firmware/APK, explains connection choices and checks the latest stored upload under your account. The browser cannot verify the phone’s Bluetooth link.

Open on phone gives account-first instructions. Existing website QR pairing is an explicit alternative. Your templates/groups, Dashboard View/Edit, Rules, Analytics, exports and old downloads remain.
