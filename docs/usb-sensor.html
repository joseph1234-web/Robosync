01

PREPARE

Keep the board’s current sketch.

Uploading replaces its program. Save the original sketch/settings first, or use a spare board. Open the starter’s firmware/RoboSynctUsbSensor/RoboSynctUsbSensor.ino in Arduino IDE, install Espressif core 3.3.12 and select ESP32 Dev Module.

Use an original ESP32 DevKit V1. This starter does not support ESP32-C3/S3/CAM or Arduino Uno.

Wire with board power disconnected
PotentiometerESP32
One outer terminal3V3
Other outer terminalGND
Center terminal / wiperGPIO34 / D34

Use a data cable. Never apply 5 V to GPIO34. Readings are uncalibrated raw counts, 0–4095. A floating pin is not a sensor test.

02

PREVIEW

Watch the value change locally.

Verify and upload the sketch yourself after checking the board. Close Serial Monitor. Extract the ZIP and open PowerShell in that folder. Install the serial dependency, list ports, then replace COM8 with your actual port.

py -3 -m pip install -r requirements.txt
py -3 usb_bridge.py --list-ports
py -3 usb_bridge.py --port COM8 --limit 3

Turn the potentiometer. Expect three changing raw values marked local only, then a stop. This preview makes no cloud request and stores no upload queue.

macOS/Linux: use python3 and your listed /dev/cu… or /dev/tty… port. Full instructions are inside the ZIP.

03

SELECT THE SAVED STREAM

Use your existing device IDs.

In RoboSynct, open your project and select a registered hardware ESP32. Use Add stream → Potentiometer, or select it if it already exists. Choose Download USB binding below the device guidance, then Save binding file in its review dialog. Put RoboSynct_USB_Binding.json beside usb_bridge.py. If downloads are blocked, choose Copy JSON and save it in Notepad using All files and UTF-8. Open Manual save instructions and JSON if clipboard access is unavailable; keep the exact .json filename.

The binding contains public backend configuration and existing record IDs. It never contains your password, account token or Wi-Fi password. Other sensors and dashboards stay in place.

04

SEND AND CHECK

Choose a short cloud test.

py -3 usb_bridge.py --port COM8 --send --limit 12

Enter your RoboSynct email/password in the terminal. The password is hidden and not saved. Use your app account, not a ChatGPT or database administrator password. The adapter checks owner access and the stream before sending.

After saved appears, choose Sensor data → Refresh on the website. Bind a value widget and chart to that stream and save. Refresh the dashboard and sync your existing paired phone.

One sample per five seconds, 12 by default. Ctrl+C stops. Failures stop after bounded retries. No existing data is overwritten or deleted. Raw readings use desktop receive time and estimated quality. Saved readings do not prove a current physical link.

When a step stops

No port or no packets?

Check the data cable, selected port and board driver. Close Serial Monitor. The adapter stops after 20 seconds without valid sensor data.

Binding or sign-in refused?

Select your hardware ESP32 and Potentiometer raw input. Keep account security enabled. CAPTCHA/MFA challenges and social-only sign-in are not supported by this first adapter.

No internet?

Local preview still works. Cloud sending stops; samples are not silently queued. The existing Android cached dashboard remains available within its grant.
