Keep the Dashboard appearance together.

  1. On the website, open your project → Dashboard.
  2. Select a Dashboard theme. Current website colors · save to phone captures the website’s current color theme. Individual widget themes remain.
  3. Use Edit to choose each card’s width and height, then Save dashboard.
  4. Update the APK and tap Sync. The saved colors, icons, sizes and order remain available offline.

Both screens use the same six palettes and twelve vector icons. Gauge, progress, status and history styles match. Fixed card heights apply in View and Edit; height 0 stays automatic. At 720 logical pixels or narrower, both stack cards at full width. Larger screens use the saved columns. Font rendering and accessibility text scaling can differ by platform.

Physical pin and virtual label are different.

FieldESP32 potentiometerArduino Uno example
Physical inputGPIO34A0
Optional data labelV0V0
Where to connect a wireThe board header marked 34 / GPIO34The header marked A0

V0 has no physical location. It labels a data stream in software. Your compatible sketch reads the actual GPIO or analog input. Find the physical pin’s printed label using your exact board’s pinout.

Choose a stream’s pin.

  1. Website → your existing project → Devices.
  2. Select the device and sensor stream, then Pin setup. Add stream also offers pin fields.
  3. Choose the physical board pin and, optionally, a virtual data label V0–V255. A multi-stream module is assigned per stream after adding it.
  4. Save pin setup. This retains the stream ID, history and widget bindings. Tap Sync in the account-connected APK to cache the details.

This saves a wiring plan. It does not detect wires or change firmware. The current RoboSynct ESP32 starter still reads GPIO34. A different pin requires changing SENSOR_PIN in a compatible sketch and uploading it separately. Arduino Uno needs a compatible Uno sketch and ingestion adapter; the ESP32 sketch cannot run on Uno. Pin selection alone does not add a sensor driver or Blynk protocol support.
