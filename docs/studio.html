Advanced outputs and remote video

LED/relay Switches need Boolean outputs; Servo uses a bounded angle output. All controls require matching authenticated firmware. I/O 1.6 retains explicit Apply fields, three-pin RGB, one-shot boot-scoped schedules and bounded heat-only thermostat sessions. I/O 1.6 adds explicit relay polarity and detached-at-start servo signals. Old sensor firmware remains read-only.

Camera cloud mode currently provides protected snapshots. Remote live video requires a selected outbound secure relay with bandwidth and access limits; snapshots are never labeled live.
