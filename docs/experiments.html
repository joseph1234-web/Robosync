01 / CHOOSE

Start with your device.

On Home, choose Start an experiment. Reuse an owned project and device, or name a new project and register an original ESP32 in the same reviewed flow. Then choose Review missing setup and Continue to Dashboard. For other saved templates, open your existing project and choose Experiments & groups. Select a template and the existing target device. For your current setup, choose ESP32 USB potentiometer and your ESP32 Lab device.

Need another device in an existing project? Choose a new device in quickstart, or use Register a device in Experiments & groups. Choose simulation explicitly for practice data.

02 / REVIEW

Keep what already works.

Choose Review experiment. The review lists reused stream IDs, missing streams, existing cards and missing cards. A conflicting key stops setup so its history stays intact.

Continue to Dashboard adds missing streams and places missing cards in a draft. Review it, then choose Save dashboard. Repeating a starter reuses compatible cards, including their custom colors, sizes and titles.

03 / REUSE

Save your own experiment.

In Dashboard, choose Save blueprint, select the device and enable Also save device streams as a reusable experiment starter. Give it a name, then open Experiments & groups and choose Save library.

The starter links a versioned template to its matching blueprint. Existing devices, rules and readings stay in their project.

04 / TAKE IT WITH YOU

Find it offline, too.

Update the APK in place and tap Sync in account mode. Devices shows cached project devices; filter by group, device, name or mode. Readings and history can download another stream’s recent samples while online.

Downloaded readings and filters reopen offline. More → Experiment starters shows your cached starter names. Creating a starter needs website internet access.

One saved Dashboard. A clearer view.

Temporary filters affect the view. They do not remove widgets or rewrite the Dashboard. Edit / Arrange returns to all cards. Existing widget colors, vector icons and responsive sizes continue to use the shared website and APK design.

Offline account limits: up to 1,000 device definitions, 1,000 stream definitions, 100 readings per Dashboard-bound stream, eight additional downloaded streams and 50 recent project events. A partial catalog is labeled; group counts describe cached metadata. Legacy QR mode retains its Dashboard-bound scope.

ESP32 potentiometer firmware remains compatible. Android1.6.0 also reads the supplied Direct1.1.1 potentiometer + DHT extension; see the sensor upload fix. Other sensors need compatible firmware and an ingestion adapter; templates define data and do not install drivers. No hardware testing or flashing is part of this software update. Motor operation is deferred until a motor driver is available. Earlier passing phone tests remain recorded; this release still needs phone/offline acceptance after software delivery.
