V0, V2 and other virtual labels name data. They are not physical board pins. This is a configuration report; it cannot detect your wiring.



3. Use the profile when you need it
  1. Download the Sensors 1.3.0 starter and open the sketch named in your reviewed compiler target in Arduino IDE.
  2. Place the reviewed RoboSynctSensorConfig.h beside the sketch. Keep all the other supplied tabs.
  3. For ESP32 profiles, retain your private RoboSynctUserConfig.h from Easy ESP32 setup. Uno USB does not use a Bluetooth setup key. Keep the same board setup key and leave Erase All Flash disabled to preserve enrollment.
  4. Review the wiring with the board unpowered, using the voltage and pin labels for the selected board (ESP32:3.3 V; Uno:5 V). Choose the reviewed board target. ESP32 profiles use 4 MB flash and Huge APP (3 MB); Uno uses its standard Uno target. Use Verify now. Upload manually only when hardware testing resumes.
  5. In the website, preview the matching board/sensor experiment starter on your existing device. Save the Dashboard, then Sync the phone. ESP32 uses Connect device and Auto-sync. Uno uses the reviewed USB binding and laptop bridge to deliver readings to the website; the APK syncs those same streams.
  6. Hardware tests are deferred until the software phase is finished. This helper never flashes, opens a serial port or connects to a board.
