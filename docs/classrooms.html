01 / MY PROJECTS

Your existing lab stays yours.

Owned projects keep their existing offline Dashboard, widget styles, board keys and upload queues. Classroom membership never changes project ownership, signs you into another account or connects another person's board.

In Android, choose More → Shared with me. The account screen also offers Shared with me when you have signed in but have no owned project.

02 / SHARED WITH ME

Approve first. Share deliberately.

Website Home → Shared with me or Alerts, classrooms & camera → Classrooms. Class owners generate a private invitation and approve join requests. Project owners separately choose teachers or approved class members as the audience.

Creating a classroom uses a stable request ID. Retrying a lost response does not create another class. Owner and teacher tools remain in the website; the APK is a reader.

03 / READ-ONLY DASHBOARD

Same cards, limited access.

The APK reuses the existing widget renderer, colors, icons and responsive sizes. Shared views cannot edit layouts, bind streams, upload readings, provision boards or drive motors.

Shared views need internet to recheck permission every 15 seconds while open. Leaving or losing verification clears the view; it never replaces your private offline cache. Private camera cards become an inert note. Media URLs, router settings and nested private configuration are excluded.

04 / CLOUD AND CAMERA

Know where it runs.

Cloud sensor rules can now be edited as well as paused/resumed. A condition sentence explains trigger/reset; hold, cooldown and gap are under Timing options. Empty numeric fields are rejected, and retrying a lost save uses the same ID and token.

Protected camera preview still starts explicitly. A failure or stop clears the saved-frame state. Snapshots require a current frame from the same account, at most five seconds old. Camera details and Forget camera provide recovery without showing its private token.
