01 / OPEN YOUR EXISTING RULE

Activity → Manage phone-local alert

Install the update over the existing APK. Sign in to your existing project and connect its existing Potentiometer target once. The editor also opens for that saved board while offline or paused.

Saved values load automatically. The rule keeps its identity when edited. A board mapped to another project cannot be edited from this project.

02 / CHOOSE YOUR CONDITION

Above or below?

Choose Above or Below, a trigger value and a reset value from 0–4095 raw. A live sentence explains exactly when a warning and reset occur. Zero is a valid reading.

For Above, reset at/below the trigger. For Below, reset at/above it. Hold, cooldown and maximum sample gap are under Timing options. Invalid entries stay in the form for correction.

03 / PREVIEW BEFORE SAVING

Try saved readings.

Preview evaluates up to 100 saved samples from the current mapping with the same phone-local runner. It shows warning/reset counts and up to six example events.

Preview never saves a rule, creates real events or uploads data. It starts with a fresh evaluation state. Actual collection can differ because live state and later readings continue.

04 / SAVE, PAUSE, RESUME

Your choice, clearly shown.

Save and resume applies the condition to new collected readings. Saving unchanged values keeps the active/cooldown state. Old samples are not replayed into real events.

Pause stops this rule's evaluation and keeps sensor collection, old events and queued uploads. Save and resume starts it again. Open Activity to see actual events; Auto-sync can deliver new queued events when phone internet returns.
